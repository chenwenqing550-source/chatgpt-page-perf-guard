# v1.7 Performance + Handoff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布一个更低干扰、更可诊断的 v1.7.0：页面繁忙时扩展主动让路，减少生成中/滚动时的额外主线程竞争，并内置安全的结构化换窗交接能力。

**Architecture:** 保留现有 `core.js` 的压力/窗口建议核心计算，重点重构 `monitor.js` 的采样生命周期和 `styles.css` 的优化作用范围；新增轻量交接模板能力并通过 popup 调用。所有诊断仅内存、无正文、无联网、无自动发送。

**Tech Stack:** Manifest V3 WebExtension, vanilla JavaScript/CSS/HTML, Node.js `node:test`.

**Spec:** `docs/superpowers/specs/2026-09-12-v1.7-performance-handoff-design.md`

## Global Constraints

- 版本目标固定为 `1.7.0`。
- 零联网、零遥测、零聊天正文持久化。
- 默认不自动扫描完整聊天正文做本地压缩。
- 不自动创建新聊天、不自动点击发送。
- 页面越忙，扩展主动工作越少。
- 近视口/正在增长的消息不得进入远屏冷却优化。
- 取不到可靠信号时保持 `UNKNOWN`，不得把缺失数据写成 0。
- 旧 v1.6.1 只保留 Git 历史；README/安装入口/Release 推荐面只指向新版本。旧 Release 真正删除放在 v1.7.0 验证通过并发布之后。

### Task 2: 重构监控采样，消除繁忙时主动抢主线程

**Files:**
- Modify: `extension/monitor.js`
- Test: `tests/monitor-compat.test.js`
- Test: `tests/monitor-load-shedding.test.js`

**Interfaces:**
- Consumes: Task 1 lifecycle helpers.
- Produces: message `getPerfMetrics` 中新增 `activityState`, `activeProbeSuppressed`, `selfWorkMs`, `recentIncidents`。

- [ ] **Step 1: 写失败测试**
  - 源码检查：scroll/generating/busy 路径不得调用 `estimateCoverage()` / 批量 `getBoundingClientRect()`。
  - passive signals available 时 `runFrameBurst()` 不作为固定 5 秒主路径。
  - `document.hidden` 时非必要采样停用。
  - MutationObserver 不读取正文，只记录 mutation 数/时间。
  - 诊断 ring buffer 不保存 textContent/innerText/message body。

- [ ] **Step 2: 运行相关测试，确认 RED**
  - Run: `node --test tests/monitor-compat.test.js tests/monitor-load-shedding.test.js`

- [ ] **Step 3: 最小实现**
  - wheel/touchmove/pointermove/scroll 只更新时间戳，passive listener。
  - MutationObserver 只做计数和最后 mutation 时间。
  - 通过状态机决定是否允许主动 probe。
  - coverage 改为低频、quiet-only；优先使用 IntersectionObserver 维护 near/far 计数，兼容失败时再有限采样。
  - LoAF/LongTask 事件写入 ring buffer；扩展主动工作用 `performance.now()` 前后差记录 `selfWorkMs`。

- [ ] **Step 4: GREEN + 全量现有测试**
  - Run: `npm test`
